# STARFALL // 8-BIT

A browser-based 8-bit space-combat game built with HTML5 Canvas and JavaScript.

## Features

- 8 campaign sectors
- Multi-wave enemy combat
- Boss encounters
- Pixel-art rendering drawn directly with Canvas
- Keyboard movement and mouse aiming
- Energy-based weapons
- Dash mechanic
- Hull and energy HUD
- Score and persistent high score
- Sector selection and progression
- Particle effects, screen shake, starfield, grid and hit effects
- Responsive game shell
- No external game engine required

## Run locally

Open `index.html` in a modern browser.

## GitHub Pages

The game can be published from the `game` directory when using a deployment setup that supports a project subdirectory. If Pages is configured to publish the repository root, move/copy the game entry point to the published directory or configure the Pages source accordingly.
